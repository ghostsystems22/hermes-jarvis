# Makro Phuket grocery run example

Session notes for a real planning run combining Calendar, Drive, Sheets, and Maps.

## Situation
- Home base: **The Base Central condominium, Phuket**
- Store target: **Makro Thalang, Phuket**
- User was staying in Chalong / The Base Central area.
- Grocery list came from a spreadsheet named **`12 weeks.xlsx`** in Google Drive.

## What the sheet contained
Main grocery items extracted from the nutrition plan:
- eggs
- oats
- bananas
- Greek yogurt
- whey
- berries
- chicken / beef
- rice / potatoes / sweet potato
- salad / vegetables
- salmon / tuna
- cottage cheese
- peanut butter
- black coffee

## Useful planning facts
- Drive search found the spreadsheet as a `.xlsx` file, not a native Google Sheet.
- Best workflow was: **Drive search → Drive download → local parse**.
- Calendar had no sufficiently long open block for a same-day wholesale run.
- Travel to Makro Thalang from The Base Central was roughly **18.1 km / ~20 min driving**.
- Makro Thalang hours from web lookup were **6:00 AM – 11:00 PM daily**.

## Time estimate used
- **Travel:** ~40 min round trip
- **In-store shopping:** ~45–60 min for the full list
- **Total:** ~1h25–1h40

## Outcome
- The same-day slot was rejected because the calendar gap was too short.
- Recommended action: move the run to a day with a 2-hour free block, or use delivery/pickup.

## Reusable lesson
For errand planning, always combine:
1. shopping list size
2. store hours
3. commute time
4. a real calendar gap

Do not recommend a slot just because it is open on the calendar if the trip cannot physically fit.
